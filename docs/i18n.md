# Client localization

Client localization is owned by `packages/gui/src/common/i18n.rs`, with compile-time embedded JSON catalogs in `packages/gui/resources/locales/{en,ko}.json`. Feature-local `i18n.rs` modules also own copy ported from formerly hard-coded labels.

The client ships English and Korean only. The language setting offers System, English and Korean. `language_preference` preserves the language of region/script variants (`ko-KR` → Korean, `en-GB` → English); removed or unknown languages render English without rewriting the saved value. System reads the OS locale through `sys-locale`, using Korean for a Korean locale and English otherwise. It does not search an ordered device-language list.

Use `common::{tr,tr_args,tr_count}` for catalog copy. Keys use dotted lookup; count suffixes try explicit zero/one/two before the English one/other or Korean other category. Interpolation uses `{{name}}`. Lookup falls back to English and then the key. Do not change protocol strings or user content to compensate for a missing translation.

Translate labels, controls, empty states, confirmation copy and local wrappers. Do not translate provider output, persisted identifiers, paths, API tags or raw diagnostic evidence. Preserve placeholders and plural semantics across catalogs. Provider/forge-specific nouns must match the actual selected service rather than be inferred from English UI text.

Changing locale must not recreate sessions, reset drafts, lose host selection or mutate daemon configuration. Respect right-to-left layout, text expansion, text scaling and accessibility labels. Native controls, errors and retry states need translation as well as the happy path.

Executable plugin translations are not a UI extension mechanism. Backend plugins may return data; they do not install catalogs or executable components into the Rust client.

Verify catalogs and visible flows on the actual native client. A website locale check or a former TypeScript app translation test does not establish native coverage. See [testing](testing.md) for recorded evidence and missing platform execution.
